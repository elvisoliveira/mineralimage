# Mineral Image

This repository is dedicated to preserving and showcasing a historical reconstruction of a website I developed in 2009 while employed at **2DA Branding & Design**. The website was built for **Mineral Image**, an agency project designed to display high-quality portfolio images. The company has since ceased maintaining the original site, which led to its eventual discontinuation.

## Purpose

The primary goal of this project is nostalgia and historical preservation. By restoring the site, I aim to create a digital archive of my work and celebrate my professional journey.

## Reconstruction Process

The restoration process involved retrieving resources from the Wayback Machine and adapting them for modern static site hosting:

- **Original Stack:** The original website was built with **Drupal** using **PHP templating**.
- **Static Site Generation (SSG):** For the reconstruction, I used an adapted **Twig** script to assemble the static site files.
- **Data Source:** The website was recovered from the following Wayback Machine snapshot:
```
https://web.archive.org/web/20200220214325/http://www.mineralimage.com/
```
- **Hosting:** The static version of the restored site is hosted on **GitHub Pages**.
